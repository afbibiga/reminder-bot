# Настройка webhook для Amvera

## Проблема

Бот на Amvera не работал, потому что использовал **polling** вместо **webhook**. На облачных платформах polling не работает — Telegram не может достучаться до бота.

## Решение

Добавлена поддержка webhook с возможностью переключения между режимами через переменные окружения.

---

## Настройка на Amvera

### 1. Узнайте URL вашего приложения

После деплоя на Amvera вы получите URL вида:
```
https://your-app-name.amvera.ru
```

### 2. Добавьте переменные окружения в Amvera

В настройках проекта на Amvera добавьте следующие переменные окружения:

```bash
WEBHOOK_ENABLED=true
WEBHOOK_URL=https://your-app-name.amvera.ru/webhook
```

**Важно:** Замените `your-app-name.amvera.ru` на реальный домен вашего приложения!

### 3. Перезапустите приложение

После добавления переменных окружения перезапустите приложение на Amvera.

### 4. Проверка

Откройте в браузере:
```
https://your-app-name.amvera.ru/health
```

Должен вернуться ответ:
```json
{"status": "ok"}
```

Теперь бот должен отвечать в Telegram!

---

## Локальная разработка

Для локальной разработки **НЕ** добавляйте `WEBHOOK_ENABLED` в `.env` или установите:

```bash
WEBHOOK_ENABLED=false
```

Бот будет работать в режиме polling (как раньше).

---

## Как это работает

### Режим Polling (локально)
- Бот сам опрашивает Telegram API каждые несколько секунд
- Удобно для разработки
- Не работает на облачных платформах

### Режим Webhook (Amvera)
- Telegram сам отправляет обновления на ваш сервер через HTTP POST
- Работает на облачных платформах
- Более эффективно для production

---

## Проверка логов

После запуска в логах должна появиться строка:

**Webhook режим:**
```
Запуск в режиме WEBHOOK: https://your-app-name.amvera.ru/webhook
Webhook установлен: https://your-app-name.amvera.ru/webhook
```

**Polling режим:**
```
Запуск в режиме POLLING
```

## Возможные проблемы

### Бот не отвечает после настройки webhook

1. Проверьте, что `WEBHOOK_URL` указан правильно (с `https://` и `/webhook` в конце)
2. Убедитесь, что приложение запущено на Amvera
3. Проверьте логи приложения на Amvera

### Ошибка "WEBHOOK_URL должен быть задан"

Добавьте переменную окружения `WEBHOOK_URL` в настройках Amvera.

### Локально бот не работает

Убедитесь, что `WEBHOOK_ENABLED=false` или переменная не задана в локальном `.env`.
