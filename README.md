# Напомню обо всем

Полностью рабочий Telegram-бот-напоминалка с веб-админкой.

## Что реализовано

- `/start` - приветствие и список команд
- `/add [текст] [дата время]` - добавить напоминание
- `/list` - показать активные напоминания
- `/delete [номер]` - удалить напоминание по номеру из `/list`
- `/help` - справка
- Фоновая проверка напоминаний каждую минуту
- Хранение пользователей и напоминаний в SQLite
- Встроенная админка с Basic Auth

## Формат команды `/add`

Пример:

```text
/add Позвонить врачу 2026-04-15 14:30
```

Правила:

- Формат даты: `ГГГГ-ММ-ДД`
- Формат времени: `ЧЧ:ММ`
- Если дата не указана - `текущее время + 1 час`
- Если время не указано - `09:00`
- Если указано только время - используется сегодняшняя дата
- Время должно быть в будущем

## Переменные окружения

Проект читает настройки из файла `.env` (через `python-dotenv`).

Обязательные:

- `BOT_TOKEN` - токен Telegram-бота

Основные:

- `BOT_TIMEZONE=Asia/Irkutsk`
- `BOT_DB_PATH=reminders.db`

Админка:

- `ADMIN_ENABLED=true`
- `ADMIN_HOST=127.0.0.1`
- `ADMIN_PORT=8080`
- `ADMIN_LOGIN=admin`
- `ADMIN_PASSWORD=change_me_now`

## Запуск

```powershell
cd telegram_reminder_bot
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Заполните `.env` (минимум `BOT_TOKEN`), затем:

```powershell
python bot.py
```

## Админка

После запуска:

- `http://127.0.0.1:8080/admin`

Логин/пароль берутся из `.env` (`ADMIN_LOGIN`, `ADMIN_PASSWORD`).

## База данных

Таблицы:

- `users` - пользователи (telegram id, username, имя, язык, даты)
- `reminders` - напоминания

Это база для следующего этапа (монетизация): можно добавлять подписки, платежи, лимиты и роли.
